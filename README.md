SOLMAR HEAT is a top-down 2D open-world crime game set in the fictional city of Solmar: explore the city on foot and by car, steal cars, run four story missions for the fixer Milo, dodge traffic and pedestrians, fight back, shake a five-star wanted level and the Solmar PD, and watch it all on a HUD with a live minimap. Progress saves to localStorage between visits. Plain static files, playable offline in desktop Chrome.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.

## How to play

- **WASD** — walk / run
- **E** — steal / exit a car
- **Punch** — fight back on foot
- **Missions** — follow Milo's jobs: WHEELS, THE PIER DROP, HEAT, PAYDAY RUN
- **Wanted 0–5 stars** — foot cops and cop cars hunt you down; get BUSTED or WASTED and you start over from your last save
